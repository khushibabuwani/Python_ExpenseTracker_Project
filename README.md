# Python Expense Tracker

## About the Project
A Python and MySQL-based Expense Tracker application designed to record, manage and track daily expenses.

## Technologies Used
- Python
- MySQL
- MySQL Connector

## Features
- Add new expenses
- View recorded expenses
- Calculate total spending
- Update expense records
- Delete expense records
- Store expense details in MySQL

## Database
Database Name: `expense_db`

Table Name: `expenses`

## How to Run
1. Install Python and MySQL.
2. Install MySQL Connector:
   `pip install mysql-connector-python`
3. Create the database and required table.
4. Configure your MySQL connection credentials.
5. Run the Python file.

- Python and SQL integration
- Database connectivity
- CRUD operations
- Data retrieval and aggregation
